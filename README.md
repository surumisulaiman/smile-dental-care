# Smile Dental Care & Your Dental Clinic

Responsive website for Smile Dental Care (South Chittoor) and Your Dental Clinic (Cheranalloor), Kochi. Built with HTML, CSS and JavaScript.

## Preview

Run `python3 -m http.server 4173 --bind 127.0.0.1` and open http://127.0.0.1:4173.

JavaScript syntax check: `node --check script.js`.

## Branches

The clinic switcher updates branding, location information and appointment links, and remembers the selection for the browser session. Smile Dental Care links to its existing Gonimo booking page. Cheranalloor contact details and booking link are pending confirmation; its appointment links lead to the branch information section.

## Before launch

Confirm Cheranalloor address, contacts, booking destination and treatment availability. Confirm opening hours for both clinics. Replace the illustrative Unsplash clinic photograph and monogram placeholders with approved clinic and team photography. Fonts load from Google Fonts.
